# M3 — Interactive exercises

Build milestone M3. Each exercise is a reusable component bound to a blockId, with instructions, timebox, roles, expected output, autosave, submit, facilitator review and a "compare with answer key" view after unlock.

- BriefChallenger (02.01): rewrite the request, list clarification questions, choose and justify an approach.
- CredentialPicker (02.02): shortlist 3 using relevant / sourced / shareable; pick one lead proof point.
- ClientIntelBrief (02.03): 9 headings, each line tagged FACT or ASSUMPTION.
- InterviewGuide + ObservationGrid (03.03); EvidenceTagger (03.02).
- PersonaBuilder (04.01): 11 fields, behaviour clusters.
- JourneyMapBuilder (04.02, 05.04 future mode): stages as columns; rows Actions / Touchpoints / Thoughts / Feelings / Pain points + evidence ID / Opportunities; emotion curve; mark 2 moments that matter; 3 How Might We questions. Validation: a pain point needs an evidence ID or the tag TO VALIDATE; an HMW must be a question, not a solution.
- InspirationSheet (04.03), ConceptSheet (04.04), IdeaSheet with 11 fields (05.07).
- PreReadPlanner + PodcastPlanner (04.05, 04.06): page plan, word counter, 150 wpm duration, "does it reveal the answer?" checklist.
- ImpactEffortMatrix with agreed criteria before voting (06.02); ValuePropositionCanvas (06.03); PilotCanvas with baseline, measures, decision rule (06.X4); Roadmap Now / Next / Later (06.X5).
- ChallengeRound: each group questions another group's output.
Answer keys: never sent to participants before unlock; unlock when every group has submitted or the facilitator forces it. Add an API test proving a participant cannot fetch an answer key early. Stop and report.
